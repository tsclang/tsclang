# 00.7.12 install — установка зависимостей

## Синтаксис

```bash
tsclang install                    # синхронизация по манифесту
tsclang i                          # алиас
tsclang install <пакет>[@<версия>] # добавить зависимость
tsclang install <файл.tspkg>       # установить из локального архива
tsclang install git+<url>          # из git-репозитория
```

## Описание

Семантика — как у npm: команда с именем пакета меняет манифест, bare-вызов приводит лок-файл в соответствие манифесту.

**Синхронизация (без аргументов).** Читает `tsc.package.json` из текущей директории и приводит лок-файл в соответствие манифесту: недостающие зависимости добавляются, изменившиеся версии обновляются, отсутствующие в манифесте — удаляются. По умолчанию ставятся `dependencies` + `devDependencies`; с `--production` — только `dependencies`. Итог: `N installed, M updated, K removed` или `Already up to date`.

**По имени (npm-семантика).** Дописывает зависимость в `dependencies` манифеста (при отсутствии `tsc.package.json` создаёт минимальный), создаёт каталог `tsc_packages/<имя>/` и пинит точную версию в лок-файле:

```bash
tsclang install mylib          # latest → "^1.0.0" в dependencies
tsclang install mylib@^1.2.0   # constraint как указан
tsclang install git+https://github.com/example/mylib
```

Без версии constraint берётся как `^<latest>`, с версией — как передан. Вывод: `Installed <имя>@<версия>`. Реестр пакетов пока в разработке, поэтому загрузка кода по имени не выполняется — фиксируются манифест, лок-файл и каталог.

**Из архива `.tspkg`.** Распаковывает содержимое пакета в `tsc_packages/<имя>/`, дописывает точную версию в `dependencies` и фиксирует в лок-файле с source `local`. Архив создаётся командой `tsclang publish` (00.7.16-publish.md).

## Опции

| Опция | Описание |
|-------|----------|
| `--production` | Синхронизация: только `dependencies`, без `devDependencies` |

## Примеры

```bash
tsclang install                          # всё из манифеста
tsclang i                                # то же самое
tsclang install --production             # только прод-зависимости
tsclang install mylib@^1.2.0
tsclang install ../mylib-0.1.0.tspkg
```

## Коды выхода

- 0 — зависимости установлены/синхронизированы
- 1 — нет `tsc.package.json` (bare), архив не найден или повреждён
