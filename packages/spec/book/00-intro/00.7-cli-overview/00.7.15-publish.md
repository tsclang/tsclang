# 00.7.15 publish — упаковка пакета

## Синтаксис

```bash
tsclang publish
tsclang p      # алиас
```

## Описание

Собирает текущий проект в JSON-архив в текущем каталоге: `<имя>-<версия>.tspkg` — формат для `tsclang install <файл.tspkg>`. Для scoped-имён `/` в имени файла заменяется на `-`: `@tsclang/probe` → `@tsclang-probe-1.0.0.tspkg`.

Требования: в текущем каталоге есть `tsc.package.json` с полями `name` и `version`.

В архив включаются рекурсивно все `.tsc`-файлы проекта (включая `.d.tsc`-декларации), C-заголовки `.h` и файлы тулчейнов (`toolchain.cmake`) — они нужны пакетам платформ, — и сам `tsc.package.json`. Исключаются каталог `tsc_packages/` (установленные зависимости) и скрытые файлы/каталоги (начинаются с `.`). `devDependencies` в архив не попадают.

Итог: `Published <имя>@<версия> (N files)`.

## Пример

```bash
tsclang publish    # → mylib-0.1.0.tspkg
```

## Коды выхода

- 0 — архив создан
- 1 — нет `tsc.package.json`, невалидный JSON или отсутствуют `name`/`version`
