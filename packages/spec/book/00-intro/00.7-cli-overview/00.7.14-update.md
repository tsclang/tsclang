# 00.7.14 update — обновление зависимости

## Синтаксис

```bash
tsclang update <пакет>
```

## Описание

Обновляет запись пакета в лок-файле до версии `latest`. Сама загрузка происходит при следующей синхронизации `tsclang install` (00.7.13-install.md).

Вызов без имени пакета пока не реализован.

## Пример

```bash
tsclang update @tsc/sqlite3
```

## Коды выхода

- 0 — запись обновлена
- 1 — ошибка лок-файла
