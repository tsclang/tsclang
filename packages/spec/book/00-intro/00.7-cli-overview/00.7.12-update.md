# 00.7.12 update — обновление зависимостей

## Синтаксис

```bash
tsclang update          # все зависимости манифеста
tsclang u               # алиас
tsclang update <пакет>  # одна зависимость
```

## Описание

Пересолвляет constraint из `dependencies`/`devDependencies` манифеста в максимально удовлетворяющую точную версию и записывает её в лок-файл. Лок-файл обновляется, но никогда не стирается.

**С именем пакета.** Constraint берётся из манифеста; запись в лок-файле обновляется до новой версии:

```
$ tsclang update mylib
Updated mylib 1.0.0 -> 1.2.3
```

Если текущей записи в лок-файле не было, вывод `Updated mylib -> 1.2.3`. Пакета нет в манифесте — ошибка `package '<имя>' is not in tsc.package.json`, exit 1.

**Без аргументов.** Пересолвляет все зависимости манифеста, удаляет из лок-файла записи без записи в манифесте (авто-install, как у bare `tsclang install`) и печатает итог: `Updated 2 packages` или `Already up to date`.

## Примеры

```bash
tsclang update
tsclang u mylib
```

## Коды выхода

- 0 — зависимости обновлены или уже актуальны
- 1 — нет `tsc.package.json`, пакет не найден в манифесте
