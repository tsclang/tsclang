# 00.7.7 build-cmake — генерация CMakeLists

## Синтаксис

```bash
tsclang build-cmake <tsc.package.json> [--build <имя>]
```

## Описание

Генерирует `CMakeLists.txt` для проекта с несколькими build-конфигурациями (включая кросс-компиляцию) и печатает его **в stdout** — перенаправьте в файл:

```bash
tsclang build-cmake tsc.package.json > CMakeLists.txt
```

Настройки берутся из секции `builds` манифеста. Без `--build` используется единственная сборка, если она одна; когда сборок несколько, имя обязательно.

Из сборки используются `target`, `mcu`, `toolchain`, `optimize`. Toolchain по умолчанию: `avr-gcc` для таргета `avr`, иначе `gcc`. Имя проекта — из `name` манифеста (scope `@tsc/` отбрасывается, недопустимые символы заменяются на `_`), входная точка — из `main`.

## Пример

```bash
tsclang build-cmake tsc.package.json --build desktop > CMakeLists.txt
```

## Коды выхода

- 0 — CMakeLists сгенерирован
- 1 — не указан файл манифеста, файл не читается или невалидный JSON
