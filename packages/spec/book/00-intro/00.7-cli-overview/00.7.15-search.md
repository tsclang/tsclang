# 00.7.15 search — поиск пакетов

## Синтаксис

```bash
tsclang search <запрос>
tsclang s <запрос>  # алиас
```

## Описание

Ищет пакеты в реестре по подстроке имени и печатает список:

```
$ tsclang search sqlite
Found 1 package matching "sqlite":
  @tsc/sqlite3@1.2.3 — SQLite bindings
```

Печатается последняя версия пакета и его описание. Без запроса выводится весь реестр; если ничего не найдено — `No packages found matching "<запрос>"`.

## Примеры

```bash
tsclang search sqlite
tsclang search          # весь реестр
```

## Коды выхода

- 0 — всегда (пустой результат — не ошибка)
