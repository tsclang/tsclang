# 00.7.9 format — форматирование

## Синтаксис

```bash
tsclang format <input.tsc>
```

## Описание

Форматирует исходник встроенным форматтером и **записывает результат на место** (файл изменяется in-place, резервная копия не создаётся). Стиль фиксированный — как у gofmt: отступы, кавычки, скобки, точки с запятой согласованы с конвенциями книги (блоки 01.2–01.3).

Опций нет — форматтер не настраивается.

Форматирование не меняет семантику программы.

## Пример

```bash
tsclang format src/main.tsc
```

## Коды выхода

- 0 — файл отформатирован
- 1 — не указан файл, файл не читается или содержит синтаксические ошибки
