# 00.7.3 run — компиляция и запуск

## Синтаксис

```bash
tsclang run <input.tsc> [опции] [-- <аргументы программы>]
```

## Описание

Компилирует `.tsc`-файл во временную папку, собирает системным компилятором и запускает. Stdout/stderr программы транслируются в консоль без изменений, код выхода программы становится кодом выхода `tsclang run`.

Всё после разделителя `--` передаётся запускаемой программе (не парсится CLI) и доступно в коде через `process.argv`.

## Опции

| Опция | Аргумент | Описание |
|-------|----------|----------|
| `--optimize` | `O0-O3\|Os\|Oz` | Уровень оптимизации |
| `--no-cache` | — | Игнорировать кэш компиляции |

## Примеры

```bash
tsclang run hello.tsc
tsclang run hello.tsc --optimize Os
tsclang run hello.tsc -- arg1 arg2    # process.argv: ["arg1", "arg2"]
```

## Коды выхода

- 0 — программа скомпилировалась и завершилась с кодом 0
- код программы — программа завершилась с ненулевым кодом
- 1 — ошибка компиляции или сборки
