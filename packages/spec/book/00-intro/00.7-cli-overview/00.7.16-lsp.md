# 00.7.16 lsp — Language Server

## Синтаксис

```bash
tsclang lsp
```

## Описание

Запускает Language Server Protocol-сервер на **stdio** — для интеграции с редакторами (VS Code, Neovim, JetBrains и любой LSP-совместимый клиент).

Поддерживаемые возможности:

| Функция | Что делает |
|---------|-----------|
| Hover | Тип переменной/функции по символу (`**имя**: тип`) |
| Completion | Ключевые слова, символы открытого файла, члены `Math.*` (триггер — `.`) |
| Go-to-definition | Переход к объявлению символа в текущем файле |
| Синхронизация | `didOpen`/`didChange` — полный текст документа |

Сервер отвечает на `initialize`, `shutdown`, `exit` и уведомления `$/cancelRequest`; неизвестные методы — корректная ошибка `-32601`.

Ещё не реализовано (roadmap): TCP-транспорт, find references, rename, диагностика в реальном времени, анализ на уровне полного компилятора (сейчас символы собираются сканером по тексту).

## Пример

```bash
tsclang lsp    # сервер читает LSP-сообщения из stdin
```

## Коды выхода

- 0 — корректный `shutdown`/`exit` от клиента или закрытие stdin
