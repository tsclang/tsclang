# 00.7.3 debug — отладка

## Синтаксис

```bash
tsclang debug <input.tsc>
```

## Описание

Компилирует файл с отладочной информацией и source map (`#line`-директивы связывают сгенерированный C с исходным `.tsc`), собирает во временную папку и запускает:

- если в системе найден `gdb` — запускает бинарник под отладчиком (`gdb <binary>` с каталогом исходников `.tsc` в качестве source directory): точки останова, пошаговое выполнение и просмотр значений работают на уровне исходного `.tsc`-кода;
- если `gdb` отсутствует — печатает предупреждение и просто запускает бинарник.

Требует установленный gcc (сборка) и gdb (собственно отладка).

## Пример

```bash
tsclang debug hello.tsc
```

## Коды выхода

- 0 — успешный запуск (и завершение) под отладчиком
- код программы — запуск без gdb, программа завершилась с ненулевым кодом
- 1 — ошибка компиляции или сборки
