# 00.7.1 Обзор CLI — карта команд

Раздел 00.7 — детальный справочник по CLI. Короткая вводная (создание проекта, установка пакета, первая сборка) — в 00.2.4-quick-start.md; здесь каждая команда разобрана в отдельном файле: синтаксис, опции, поведение, коды выхода.

## Карта команд

| Команда | Файл | Назначение |
|---------|------|-----------|
| `build` (`b`) | 00.7.2-build.md | Компиляция `.tsc` → C / бинарник / прошивка / CMakeLists.txt; пост-билд хук `--command` |
| `run` | 00.7.3-run.md | Именованные задачи из `scripts` в `tsc.package.json` (npm-модель) |
| `debug` | 00.7.4-debug.md | Отладка под gdb |
| `test` (`t`) | 00.7.5-test.md | Запуск тестов из `test/` |

Однобуквенные алиасы: `i`/`u`/`r` — npm/pnpm/bun, `b`/`t` — cargo, `s` — npm, `l`/`p` — мнемонические. `run` без алиаса: `r` занят `remove`, как в npm. Остальные команды алиасов не имеют.

## Глобальные флаги

| Флаг | Сокращение | Описание |
|------|------------|----------|
| `--help` | `-h` | Общий help. `tsclang <команда> --help` — справка по команде (для команд без отдельной справки печатается общий help) |
| `--version` | `-v` | Версия CLI |
| `--no-color` | — | Отключить цветной вывод |

Вызов без аргументов (`tsclang`) печатает help и завершается с кодом 0.

## Соглашения выхода

- Неизвестная команда — `unknown command '<cmd>'`, exit 1
- Неизвестная опция — `unknown option '<flag>' for '<cmd>'`, exit 1: опечатки (`--outdir`, `--out-dir`) не игнорируются молча
- Инлайн-форма `--опция=значение` не поддерживается (единственное исключение — `lint --rule=<имя>`); ошибка подсказывает форму с пробелом
