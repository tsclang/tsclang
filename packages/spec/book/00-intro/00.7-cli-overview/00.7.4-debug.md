# 00.7.4 debug — отладка

## Синтаксис

```bash
tsclang debug <input.tsc>
```

## Описание

Компилирует файл с отладочной информацией и source map (`#line`-директивы связывают сгенерированный C с исходным `.tsc`), собирает во временную папку и запускает:

- если найден `gdb` — запускает бинарник под отладчиком (`gdb <binary>` с каталогом исходников `.tsc` в качестве source directory): точки останова, пошаговое выполнение и просмотр значений работают на уровне исходного `.tsc`-кода;
- иначе если найден `lldb` — то же в LLVM-мире (`lldb <binary>`);
- если отладчика нет — печатает предупреждение и просто запускает бинарник.

Сборка подчиняется контракту тулчейнов (#282): изолированный кеш платформы (дефолтное имя — clang) или явный пин `builds.<n>.toolchain` из манифеста; голый debug без того и другого — `ConfigError` с инструкцией install-or-pin. Отладчик (`gdb`/`lldb`) — утилита просмотра, берётся из PATH.

## Пример

```bash
tsclang debug hello.tsc
```

## Коды выхода

- 0 — успешный запуск (и завершение) под отладчиком
- код программы — запуск без gdb, программа завершилась с ненулевым кодом
- 1 — ошибка компиляции или сборки
