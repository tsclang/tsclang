# 00.7.18 dev — пересборка и перезапуск при изменениях

**Не реализована.** Планируемая команда цикла разработчика: сохранил файл в IDE → инкрементальная пересборка → программа перезапустилась. Аналоги: `nodemon`, `vite dev`, `cargo watch -x run`.

## Запланированный синтаксис

```bash
tsclang dev <file.tsc> [опции]
```

Аргументы идентичны команде `run` (00.7.3). Чистая CLI-команда: никаких аннотаций в языке и специальной кодогенерации не требует.

## Запланированное поведение

1. Программа компилируется и запускается
2. Разработчик сохраняет файл в IDE
3. Изменение обнаружено → инкрементальная пересборка (только изменённые файлы)
4. Старый процесс завершается → запускается новый

- **Desktop** — kill + restart процесса
- **Embedded** (`--target avr` и др.) — пересборка + автоматическая прошивка через avrdude/openocd
- Нативный file watcher: inotify (Linux), FSEvents (macOS), ReadDirectoryChangesW (Windows)

## Текущая альтернатива

```bash
tsclang build hello.tsc -w      # пересборка при изменениях (--watch, 00.7.2)
tsclang run hello.tsc           # запуск — вручную после сборки
```

`build --watch` наблюдает за исходниками и пересобирает, но не запускает результат; `dev` добавит автоматический перезапуск.
