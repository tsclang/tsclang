# 00.7.13 install — установка зависимостей

## Синтаксис

```bash
tsclang install                    # синхронизация по манифесту
tsclang install <пакет>[@<версия>] # добавить зависимость
tsclang install <файл.tspkg>       # установить из локального архива
tsclang install git+<url>          # из git-репозитория
```

## Описание

Три режима работы:

**Синхронизация (без аргументов).** Читает `tsc.package.json` из текущей директории и приводит лок-файл в соответствие манифесту: недостающие зависимости добавляются, изменившиеся версии обновляются, отсутствующие в манифесте — удаляются. По умолчанию ставятся `dependencies` + `devDependencies`; с `--production` — только `dependencies`. Итог: `N installed, M updated, K removed` или `Already up to date`.

**Из архива `.tspkg`.** Распаковывает содержимое пакета в `packages/<имя>/` и фиксирует в лок-файле с source `local`. Архив создаётся командой `tsclang publish` (00.7.16-publish.md).

**По имени.** `пакет@версия`, `пакет` (= latest) или `git+https://...` — создаёт каталог `packages/<имя>/` и записывает зависимость в лок-файл. Реестр пакетов пока в разработке, поэтому установка по имени фиксирует зависимость без загрузки кода.

## Опции

| Опция | Описание |
|-------|----------|
| `--production` | Синхронизация: только `dependencies`, без `devDependencies` |

## Примеры

```bash
tsclang install                          # всё из манифеста
tsclang install --production             # только прод-зависимости
tsclang install @tsc/sqlite3@1.2.3
tsclang install ../mylib-0.1.0.tspkg
```

## Коды выхода

- 0 — зависимости установлены/синхронизированы
- 1 — нет `tsc.package.json`, архив не найден или повреждён
