# 00.7.12 emit-dts — генерация деклараций

## Синтаксис

```bash
tsclang emit-dts <input.tsc>
```

## Описание

Генерирует файл объявлений `<имя>.d.tsc` рядом с исходником (`hello.tsc` → `hello.d.tsc`). Файлы `.d.tsc` — интерфейсная сторона C interop: декларации экспортируемого API без реализации.

Основной инструмент для C-wrapper проектов (`tsclang init <имя> --declaration`): обёртка над C-библиотекой публикует свой API как `.d.tsc`, который затем используют другие TSClang-проекты.

После генерации печатает `Emitted <имя>.d.tsc (N declarations)`.

## Пример

```bash
tsclang emit-dts src/index.tsc   # → src/index.d.tsc
```

## Коды выхода

- 0 — декларации сгенерированы
- 1 — не указан файл, файл не читается или содержит синтаксические ошибки
