# 00.7.9 explain — объяснение ошибки

## Синтаксис

```bash
tsclang explain <код>
```

## Описание

Объясняет код ошибки компилятора по-человечески — аналог `rustc --explain`. Компилятор выдаёт ошибки в формате `error[E001]: ...`; `explain` разворачивает код в полное описание: что случилось, пример кода с ошибкой, пример исправления.

Регистр кода не важен (`e001` = `E001`).

```bash
$ tsclang explain E001
E001: cannot assign to `const` variable

Variables declared with `const` are immutable — they can only be assigned once
at the point of declaration and cannot be reassigned afterwards.
...
```

Каталог диагностик покрывает ownership (E001–E0xx), типы и остальные категории компилятора.

Без аргумента печатает список всех известных кодов — удобно для exploration.

## Примеры

```bash
tsclang explain E001
tsclang explain e012
tsclang explain          # все известные коды
```

## Коды выхода

- 0 — код найден, объяснение напечатано
- 1 — код не передан или неизвестен
