# 00.7.16 publish — упаковка пакета

## Синтаксис

```bash
tsclang publish
```

## Описание

Собирает текущий проект в архив `<имя>-<версия>.tspkg` (JSON-архив в текущем каталоге) — формат для `tsclang install <файл.tspkg>`.

Требования: в текущем каталоге есть `tsc.package.json` с полями `name` и `version`.

В архив включаются рекурсивно все `.tsc`-файлы проекта и сам `tsc.package.json`. Исключаются каталог `packages/` (установленные зависимости) и скрытые файлы/каталоги (начинаются с `.`). `devDependencies` в архив не попадают.

Итог: `Published <имя>@<версия> (N files)`.

## Пример

```bash
tsclang publish    # → mylib-0.1.0.tspkg
```

## Коды выхода

- 0 — архив создан
- 1 — нет `tsc.package.json`, невалидный JSON или отсутствуют `name`/`version`
