# 00.7.14 remove — удаление зависимости

## Синтаксис

```bash
tsclang remove <пакет>
tsclang r <пакет>     # алиас
```

## Описание

Удаляет пакет сразу из трёх мест:

- запись в `dependencies`/`devDependencies` манифеста `tsc.package.json`;
- запись в лок-файле `tsc.package.lock`;
- каталог `tsc_packages/<имя>/`.

```
$ tsclang remove mylib
Removed mylib
```

Подтверждение не запрашивается: операция локальна и обратима — `tsclang install mylib` вернёт пакет. Ни npm, ни cargo подтверждение не спрашивают. Если пакета нет ни в манифесте, ни в лок-файле, ни в `tsc_packages/` — ошибка `package '<имя>' is not installed`, exit 1. Вызов без имени пакета — ошибка `missing package name`, exit 1.

## Примеры

```bash
tsclang remove mylib
tsclang r mylib        # то же самое
```

## Коды выхода

- 0 — пакет удалён
- 1 — пакет не установлен или не указано имя
