# 00.2.3 Обзор CLI

## build — компиляция

```bash
tsclang build hello.tsc --outDir dist
```

Опции:

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--emit <c\|binary\|hex\|flash\|wasm>` | Формат вывода | `c` |
| `--outDir <dir>` | Выходная директория | `.` |
| `--target <name>` | Целевая платформа (desktop, avr, nes, wasm, ...) | `desktop` |
| `--platform <profile>` | Встроенный профиль платформы | нет |
| `--build <name>` | Именованная сборка из `tsc.package.json` | нет |
| `--mcu <chip>` | Микроконтроллер (atmega328p, atmega2560, ...) | нет |
| `--default-number <type>` | Тип чисел по умолчанию (f64, i32, ...) | из профиля |
| `--allocator <type>` | Стратегия аллокатора (heap, static) | из профиля |
| `--async <type>` | Модель async (libuv, state_machine, none) | из профиля |
| `--strict <rules>` | Strict-правила через запятую (no-any, safe-math, no-lossy-cast, ...) | нет |
| `--optimize <O0-O3\|Os\|Oz>` | Уровень оптимизации | нет |
| `--debug` | Отладочная информация | нет |
| `--sourcemap` | Генерировать source map | нет |
| `--all-errors` | Показать все ошибки (без лимита) | нет |
| `--watch`, `-w` | Пересборка при изменении | нет |
| `--no-cache` | Игнорировать кэш | нет |

Результат: `.c` файл (+ `CMakeLists.txt` если `--emit c`) или бинарник (если `--emit binary`).

## run — компиляция и запуск

```bash
tsclang run hello.tsc
tsclang run hello.tsc -- arg1 arg2
```

Компилирует во временный файл, запускает, выводит результат.

## debug — отладка

```bash
tsclang debug hello.tsc
```

Пошаговая отладка `.tsc`-программы.

## test — запуск тестов

```bash
tsclang test
```

Запускает тесты из директории `test/`.

## build-cmake — генерация CMakeLists

```bash
tsclang build-cmake tsc.package.json
```

Генерирует `CMakeLists.txt` для проекта с несколькими build-конфигурациями (включая кросс-компиляцию).

## init — создание проекта

```bash
tsclang init myapp
tsclang init mylib --library
tsclang init mywrapper --declaration
```

Создаёт структуру проекта:

```
myapp/
  tsc.package.json
  src/
    main.tsc
```

## lint — линтер

```bash
tsclang lint hello.tsc
tsclang lint hello.tsc --fix
tsclang lint hello.tsc --rule=prefer-const
```

## format — форматирование

```bash
tsclang format hello.tsc
```

## explain — объяснение ошибки

```bash
tsclang explain E012
```

## emit-dts — генерация объявлений

```bash
tsclang emit-dts hello.tsc
```

Создаёт `hello.d.tsc` — файл объявлений для C interop.

## lsp — Language Server

```bash
tsclang lsp
```

Запускает Language Server Protocol для интеграции с редакторами.

## validate-config — проверка конфигурации

```bash
tsclang validate-config tsc.package.json
```

Проверяет `tsc.package.json` на ошибки.

## install / update / search / publish — управление пакетами

```bash
tsclang install mylib
tsclang install mylib@1.2.3
tsclang update mylib
tsclang search regex
tsclang publish
```
