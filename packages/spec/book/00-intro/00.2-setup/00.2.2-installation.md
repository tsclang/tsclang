# 00.2.2 Установка

## Глобальная установка (рекомендуется)

```bash
npm install -g tsclang
```

## Обновление

```bash
npm update -g tsclang
```

## Проверка установки

```bash
tsclang --version
```

Вывод:

```
tsclang 0.1.0
```

## Запуск без установки

```bash
npx tsclang
```

## Запуск без аргументов

Вызов без аргументов печатает ту же справку, что и `--help`, и завершается с кодом 0.

Пример запуска:

```bash
tsclang
```

Вывод:

```
tsclang 0.1.0 — TypeScript-like language that compiles to C

USAGE:
  tsclang <command> [options]

COMMANDS:
  build            Compile .tsc to C or binary
  run              Compile and run
  debug            Debug a .tsc program
  test             Run tests in test/ directory
  init             Create a new project
  lint             Run linter
  format           Format source code
  explain          Explain an error code
  emit-dts         Generate .d.tsc declaration files
  lsp              Start Language Server
  validate-config  Validate tsc.package.json
  install          Install a package
  update           Update lock file
  search           Search packages
  publish          Publish a package

OPTIONS:
  --version, -v    Print version
  --help, -h       Print this help
  --no-color       Disable colored output

Run 'tsclang <command> --help' for command-specific options.
```

## Помощь по команде

Помощь доступна для любой команды: `tsclang <команда> --help`. Подробная справка по опциям есть у команд `build`, `run`, `init`, `lint` и некоторых других. Для команд, у которых нет справки, печатается общий help.

Примеры запуска:

```bash
tsclang build --help
tsclang run --help
tsclang init --help
```
