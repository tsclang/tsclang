# 00.2.3 Быстрый старт

Полный справочник по всем командам и опциям — раздел 00.7-cli-overview.

## init — создание проекта

```bash
tsclang init myapp
tsclang init mylib --library
tsclang init mywrapper --declaration
```

Создаёт структуру проекта:

```
myapp/
  tsc.package.json
  src/
    main.tsc
```

## build — компиляция и запуск

```bash
tsclang build hello.tsc --emit binary --command "./hello"   # Linux/macOS (sh)
tsclang build hello.tsc --emit binary --command ".\\hello"  # Windows (cmd)
```

Компилирует в C, собирает бинарник системным компилятором, затем выполняет команду (пост-билд хук `--command`). Аргументы программы указываются прямо в строке команды: `--command "./hello arg1 arg2"`. Подробно — 00.7.2.

## build — компиляция

```bash
tsclang build hello.tsc --out-dir dist
```

Результат: `.c` файл (+ `CMakeLists.txt` если `--emit c`) или бинарник (если `--emit binary`).

## управление пакетами

```bash
tsclang install mylib
tsclang install mylib@1.2.3
```

Пакетный менеджер пока в разработке: `install` фиксирует зависимость в лок-файле `tsc.package.lock`; запись в `tsc.package.json` и загрузка кода из реестра появятся позже.
