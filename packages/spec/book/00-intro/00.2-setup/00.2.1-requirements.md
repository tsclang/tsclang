# 00.2.1 Требования

## Обязательные

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| Node.js | >= 18.0.0 | CLI компилятора работает на Node.js |
| npm | >= 9.0.0 | Установка CLI и пакетов |

## Для компиляции в бинарник

Голый tsclang — транслятор: `.tsc` → `.c` работает без единого тулчейна. Компилирующие `--emit`
(`binary`, `exec`, `hex`, `flash`, `wasm`) требуют тулчейн, и он никогда не берётся из системы
молча (#282) — либо платформа с изолированным бандлом, либо явный пин в манифесте:

```json
{ "builds": { "app": { "emit": "binary", "toolchain": "clang" } } }
```

| Источник | Как | Что даёт |
|----------|-----|----------|
| `@tsclang/desktop` (рекомендуется) | `tsclang platform install @tsclang/desktop` | Изолированный clang в `~/.tsclang/platforms/…` — ничего системного |
| Пин `builds.<n>.toolchain` | имя компилятора в манифесте (`"clang"`, `"gcc"`, `"avr-gcc@12.1"`…) | Кеш платформы, затем PATH — пин = явное разрешение |
| CMake | >= 3.16 | Система сборки (генерируется автоматически; `--emit cmake`) |

## Для embedded (AVR)

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| avr-gcc | любой | Кросс-компиляция для AVR |
| avr-objcopy | любой | `.elf` → `.hex` (входит в avr-gcc / binutils) |
| avrdude | любой | Прошивка микроконтроллера |

## Для Web (WASM)

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| emcc (Emscripten) | любой | Компиляция C → WASM |

## Проверка установки

Каждый инструмент проверяется командой `--version`: установлен — печатает версию, нет — `command not found`. Запускайте только нужные секции. Либо проверьте всё сразу одной командой: `tsclang doctor` — отчёт по тулчейнам профиля проекта с инструкциями по установке недостающего (глава 00.7.17).

```bash
# Обязательные
node --version     # v18.x.x или выше
npm --version      # 9.x.x или выше

# Для компиляции в бинарник (пин без платформы)
clang --version    # дефолтное имя тулчейна desktop-таргета
cmake --version    # 3.16 или выше

# Для embedded (AVR)
avr-gcc --version      # любая версия
avr-objcopy --version  # входит в комплект avr-gcc
avrdude --version      # любая версия

# Для Web (WASM)
emcc --version     # любая версия
```

Примечания:

- Минимальная установка — только Node.js. Транспиляция в C (`--emit c`) не требует тулчейна.
- Дефолтный desktop-тулчейн — clang: ссылочная платформа `@tsclang/desktop` полностью на LLVM/Clang. Системный gcc/msvc не ищутся и не предлагаются; другой компилятор — явный пин `builds.<n>.toolchain`.
- На darwin-x64 апстрим LLVM не публикует сборки: clang из Xcode Command Line Tools (`xcode-select --install`) — единственное «системное» исключение.
- На Windows gcc (если запинен) должен быть из окружения MSYS2/MinGW и запускаться из его шелла: gcc, вызванный «голым» spawn из-под Windows, умирает до печати диагностики, и `tsclang` напечатает подсказку об этом.
- `emcc` появляется в PATH только после активации окружения Emscripten: `source ./emsdk_env.sh` (Linux/macOS) или `emsdk_env.ps1` (Windows PowerShell). Без активации — `command not found`, даже если emsdk установлен.
