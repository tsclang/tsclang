# 00.2.1 Требования

## Обязательные

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| Node.js | >= 18.0.0 | CLI компилятора работает на Node.js |
| npm | >= 9.0.0 | Установка CLI и пакетов |

## Для компиляции в бинарник

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| gcc или clang | любой современный | Компиляция C → бинарник |
| CMake | >= 3.16 | Система сборки (генерируется автоматически) |

## Для embedded (AVR)

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| avr-gcc | любой | Кросс-компиляция для AVR |
| avrdude | любой | Прошивка микроконтроллера |

## Для Web (WASM)

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| emcc (Emscripten) | любой | Компиляция C → WASM |

## Проверка установки

Каждый инструмент проверяется командой `--version`: установлен — печатает версию, нет — `command not found`. Запускайте только нужные секции.

```bash
# Обязательные
node --version     # v18.x.x или выше
npm --version      # 9.x.x или выше

# Для компиляции в бинарник (достаточно одного: gcc ИЛИ clang)
gcc --version      # любая версия
clang --version    # альтернатива gcc
cmake --version    # 3.16 или выше

# Для embedded (AVR)
avr-gcc --version  # любая версия
avrdude --version  # любая версия

# Для Web (WASM)
emcc --version     # любая версия
```

Примечания:

- Минимальная установка — только Node.js. Компиляция в C-код (без бинарника) не требует gcc.
- Для бинарника достаточно одного компилятора: gcc **или** clang.
- `emcc` появляется в PATH только после активации окружения Emscripten: `source ./emsdk_env.sh` (Linux/macOS) или `emsdk_env.ps1` (Windows PowerShell). Без активации — `command not found`, даже если emsdk установлен.
