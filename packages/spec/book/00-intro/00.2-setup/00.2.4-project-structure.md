# 00.2.4 Структура проекта

## Executable

```
myapp/
  tsc.package.json    — конфигурация проекта
  src/
    main.tsc          — точка входа
```

`tsc.package.json`:

```json
{
  "version": "0.1.0",
  "type": "executable",
  "main": "src/main.tsc",
  "name": "myapp"
}
```

Обязательные поля для executable:
- `name` — имя проекта
- `version` — семантическое версионирование (N.N.N)
- `type` — `"executable"`
- `main` — путь к точке входа

## Library

```
mylib/
  tsc.package.json    — конфигурация библиотеки
  index.tsc           — публичный API
```

`tsc.package.json`:

```json
{
  "version": "0.1.0",
  "name": "mylib",
  "type": "library"
}
```

Отличия от executable:
- Нет поля `main` — библиотека не имеет точки входа
- `type` = `"library"`

## Минимальный проект

Минимальный TSClang-проект — один файл:

```
hello.tsc
```

```typescript
console.log("Hello, World!");
```

Компиляция:

```bash
tsclang build hello.tsc --outDir dist
```

Никакой конфигурации не нужно — CLI работает и с одиночными файлами.

## С зависимостями

```
myapp/
  tsc.package.json
  src/
    main.tsc
  node_modules/
    mylib/
      tsc.package.json
      index.tsc
  tsc.package.lock
```

`tsc.package.json`:

```json
{
  "version": "0.1.0",
  "type": "executable",
  "main": "src/main.tsc",
  "name": "myapp",
  "dependencies": {
    "mylib": "^1.0.0"
  }
}
```

`tsc.package.lock`:

```json
{
  "version": 1,
  "packages": {
    "mylib": {
      "version": "1.0.0"
    }
  }
}
```

## Embedded-проект

```
myavr/
  tsc.package.json
  src/
    main.tsc
```

`tsc.package.json`:

```json
{
  "version": "0.1.0",
  "type": "executable",
  "main": "src/main.tsc",
  "name": "myavr",
  "builds": {
    "avr": {
      "target": "avr",
      "mcu": "atmega328p",
      "toolchain": "avr-gcc"
    }
  }
}
```

Поле `builds` определяет платформо-специфичные настройки сборки.
