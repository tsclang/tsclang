# 00.6.2 Разбор C-output async

Полный разбор async Hello World.

```typescript
async function main(): Promise<void> {
    console.log("hello async");
}
```

```c
#include "runtime.h"

typedef struct { int32_t _state; bool _done; } main_state;

static void main_poll(main_state *self) {
    switch (self->_state) {
        case 0:
            printf("hello async\n");
            self->_done = true;
            return;
    }
}

int main(void) {
    TSC_INIT();
    main_state _main_sm = {0};
    while (!_main_sm._done) {
        main_poll(&_main_sm);
    }
    return 0;
}
```

## `_state` — состояние машины

`_state` определяет, какая часть функции выполняется:
- `0` — начало функции (до первого `await`)
- `1` — после первого `await`
- `2` — после второго `await`
- ...

В этом примере нет `await`, поэтому только `case 0`.

## `_done` — флаг завершения

Когда функция доходит до конца — `_done = true`. Event loop останавливается.

## С `await`

> **Концептуальный пример** — `delay` не является встроенной функцией. Пример показывает, как `await` влияет на структуру state machine.

```typescript
async function main(): Promise<void> {
    console.log("step 1");
    await delay(1000);
    console.log("step 2");
}
```

```c
typedef struct {
    int32_t _state;
    bool _done;
    /* captured variables across await */
} main_state;

static void main_poll(main_state *self) {
    switch (self->_state) {
        case 0:
            printf("step 1\n");
            /* setup delay timer */
            self->_state = 1;
            return;
        case 1:
            /* delay complete */
            printf("step 2\n");
            self->_done = true;
            return;
    }
}
```

Каждый `await` = новый `case` в switch. Переменные, которые используются после `await`, сохраняются в struct.

## Почему так, а не через setjmp/longjmp

`setjmp/longjmp`:
- Требует stack
- Нельзя сохранить состояние и вернуться позже
- Не работает на embedded (нет OS)

State machine:
- Стек не нужен (все переменные в struct)
- Можно приостановить и возобновить
- Работает на embedded (cooperative scheduler)

## Стоимость

Каждая async функция = struct + poll function. На desktop — negligible. На embedded — каждый байт на счету, поэтому SM минимальна (только live переменные).
