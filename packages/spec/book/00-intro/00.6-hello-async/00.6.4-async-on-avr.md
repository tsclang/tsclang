# 00.6.4 Async на AVR

Async/await работает на AVR. Это не фантастика — это cooperative scheduler поверх state machine.

## Тот же паттерн

```typescript
#[target(avr)]
async function main(): void {
    console.log("boot");
}
```

Сгенерированный C:

```c
typedef struct { int32_t _state; int _result; bool _done; } main_state;

static void main_poll(main_state *self) {
    switch (self->_state) {
        case 0:
            printf("boot\n");
            self->_done = true;
            return;
    }
}

int main(void) {
    TSC_INIT();
    main_state _main_sm = {0};
    while (!_main_sm._done) {
        main_poll(&_main_sm);
    }
    return 0;
}
```

## Отличия от desktop

### State machine — singleton

На AVR heap нет. State machine размещается **на стеке** (в `main`). Для рекурсивных async — `@embedded.stack(name, N)` выделяет N слотов в BSS.

### Event loop — cooperative

Нет libuv, нет OS. Event loop = простой `while (!_done) { poll(); }`. Все задачи cooperative — сами отдают управление через `await`.

### Нет libuv

На desktop async с I/O использует libuv для неблокирующих операций. На AVR нет I/O в традиционном смысле — есть UART, SPI, I2C, GPIO. Всё синхронное, но можно мультиплексировать через cooperative scheduler.

## Пример: blink LED

> **Концептуальный пример** — `digital_write` и `delay` не являются встроенными функциями. Реальные примеры с GPIO — в Block 23 (Embedded).

```typescript
#[target(avr)]
async function main(): void {
    const led: u8 = 13;
    while (true) {
        digital_write(led, true);
        await delay(500);
        digital_write(led, false);
        await delay(500);
    }
}
```

State machine с 4 состояниями (toggle on, delay, toggle off, delay). Cooperative scheduler переключает между задачами. Нет OS, нет RTOS — только poll loop.

## Ограничения async на AVR

- Нет рекурсивных async (без `@embedded.stack`) — стек ограничен
- Нет параллельных async задач (без `Tasks<N>`) — по умолчанию singleton
- Нет I/O polling — нужно вручную через `@embedded.isr` + `EmbeddedSignal`

Подробнее — в Block 20 (Async/Await) и Block 23 (Embedded).
