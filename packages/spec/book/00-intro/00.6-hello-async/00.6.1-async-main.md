# 00.6.1 async main

TSClang поддерживает `async function main()` — асинхронную точку входа.

```typescript
async function main(): Promise<void> {
    console.log("hello async");
}
```

## Сгенерированный C-код

```c
#include "runtime.h"

typedef struct { int32_t _state; bool _done; } main_state;

static void main_poll(main_state *self) {
    switch (self->_state) {
        case 0:
            printf("hello async\n");
            self->_done = true;
            return;
    }
}

int main(void) {
    TSC_INIT();
    main_state _main_sm = {0};
    while (!_main_sm._done) {
        main_poll(&_main_sm);
    }
    return 0;
}
```

## Разбор

### State struct

```c
typedef struct { int32_t _state; bool _done; } main_state;
```

Каждая async функция компилируется в **state machine** (SM):
- `_state` — текущее состояние (какой `case` выполнять)
- `_done` — завершена ли машина
- Плюс локальные переменные, которые «живут» через `await`

### Poll function

```c
static void main_poll(main_state *self) {
    switch (self->_state) { ... }
}
```

Каждый вызов `main_poll` продвигает state machine на один шаг. `switch` определяет, какой шаг выполнить.

### Event loop

```c
while (!_main_sm._done) {
    main_poll(&_main_sm);
}
```

Простой poll loop: вызывает `main_poll`, пока SM не завершится. На desktop с libuv — полноценный event loop с I/O. В этом простом примере — sync loop, потому что нет I/O.

## Синхронный main vs async main

Синхронный:
```typescript
console.log("hello sync");
```

```c
int main(void) {
    TSC_INIT();
    printf("hello sync\n");
    return 0;
}
```

Асинхронный:
```typescript
async function main(): Promise<void> {
    console.log("hello async");
}
```

```c
typedef struct { int32_t _state; bool _done; } main_state;
static void main_poll(main_state *self) { ... }
int main(void) {
    TSC_INIT();
    main_state _main_sm = {0};
    while (!_main_sm._done) { main_poll(&_main_sm); }
    return 0;
}
```

Разница: async main генерирует state machine + poll loop. Больше кода, но позволяет `await`.
