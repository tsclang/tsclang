# 00.5.1 AVR-таргет

TSClang может компилировать код для микроконтроллеров AVR (Arduino Uno, Mega, и т.д.).

## Тот же код, другой мир

```typescript
console.log("Hello from AVR!");
```

На desktop и на AVR этот код генерирует **один и тот же** portable C c `printf` (см. 00.5.2). Платформенная адаптация происходит не в компиляторе, а в runtime и C-компиляторе: при `-DTSC_EMBEDDED` runtime переключается на embedded-реализации, а UART-консоль подключается опционально макросом `TSC_CONSOLE_UART`.

## Как скомпилировать для AVR

### Через tsc.package.json

```json
{
  "name": "myavr",
  "version": "0.1.0",
  "type": "executable",
  "main": "src/main.tsc",
  "builds": {
    "avr": {
      "target": "avr",
      "mcu": "atmega328p",
      "toolchain": "avr-gcc"
    }
  }
}
```

```bash
tsclang build src/main.tsc --out-dir dist --target avr --mcu atmega328p
avr-gcc -Os -mmcu=atmega328p -I packages/compiler/src/runtime -DTSC_EMBEDDED dist/main.c -o dist/main.elf
```

### Через `--emit cmake`

```bash
tsclang build src/main.tsc --emit cmake --build avr
```

Генерирует `CMakeLists.txt` с avr-gcc и `-mmcu=atmega328p`, без компиляции `.c`.

## Ключевое отличие: -DTSC_EMBEDDED

При компиляции для AVR определяется макрос `TSC_EMBEDDED`. Он переключает runtime:

- `String` — без ARC, без malloc. Только rodata и ring buffer
- Массивы — стек и BSS, нет realloc
- `Map`/`Set` — статические хеш-таблицы
- `console.log` — printf (portable); UART-консоль — опционально через `TSC_CONSOLE_UART`
- Нет `<stdatomic.h>`, нет pthreads
- Нет `<math.h>` (ограниченный Math)

## Что работает на AVR

- Переменные (let/const)
- Функции
- Классы (через @struct)
- Массивы (статические)
- Map/Set (статические)
- String (PROGMEM + ring buffer)
- Async/await (cooperative scheduler)
- Генераторы (singleton)
- Interrupts (@isr)
- Volatile<T> (MMIO)

## Что НЕ работает на AVR

- Threads (нет OS)
- Shared<T> / Weak<T> (нет ARC)
- Динамические массивы (no realloc)
- Полный Math (нет `<math.h>`)
- console.trace (нет stack unwinding)
