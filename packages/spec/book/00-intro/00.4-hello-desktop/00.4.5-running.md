# 00.4.5 Сборка и запуск

## Способ 1: tsclang run (рекомендуется для разработки)

```bash
tsclang run hello.tsc
```

Одна команда — компилирует, собирает, запускает. Бинарник создаётся во временной директории и удаляется после запуска.

С аргументами:

```bash
tsclang run hello.tsc -- arg1 arg2
```

## Способ 2: ручная сборка через CMake

```bash
tsclang build hello.tsc --outDir dist
cd dist
cmake .
make
./hello
```

Результат:
```
Hello, World!
```

## Способ 3: ручная компиляция через gcc

```bash
tsclang build hello.tsc --outDir dist
gcc dist/hello.c -o dist/hello -I src/runtime -lpthread -std=c11
./dist/hello
```

Флаги:
- `-I src/runtime` — путь к `runtime.h`
- `-lpthread` — threads (даже если не используются, runtime может ссылаться)
- `-std=c11` — C11 стандарт

## Способ 4: tsclang build --emit binary

```bash
tsclang build hello.tsc --outDir dist --emit binary
./dist/hello
```

Компилирует в C, затем вызывает gcc автоматически.

## С оптимизацией

```bash
tsclang run hello.tsc --optimize O2
```

Передаёт флаг `-O2` в gcc.

## Режим наблюдения (watch)

```bash
tsclang build hello.tsc --outDir dist --watch
```

Пересобирается при изменении `hello.tsc`. Удобно при разработке.
