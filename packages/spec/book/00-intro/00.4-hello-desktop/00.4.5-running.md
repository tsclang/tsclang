# 00.4.5 Сборка и запуск

## Способ 1: build --emit binary --command (рекомендуется для разработки)

```bash
tsclang build hello.tsc --out-dir dist --emit binary --command "./dist/hello"   # Linux/macOS
tsclang build hello.tsc --out-dir dist --emit binary --command "dist\\hello"    # Windows (cmd)
```

Компилирует, собирает бинарник и сразу запускает его (пост-билд хук `--command`). Бинарник остаётся в `dist/` — повторный запуск без пересборки: `./dist/hello`.

С аргументами (argv живёт в строке команды):

```bash
tsclang build hello.tsc --emit binary --command "./dist/hello arg1 arg2"
```

## Способ 2: ручная сборка через CMake

```bash
tsclang build hello.tsc --out-dir dist
cd dist
cmake .
make
./hello
```

Результат:
```
Hello, World!
```

## Способ 3: ручная компиляция через gcc

```bash
tsclang build hello.tsc --out-dir dist
gcc dist/hello.c -o dist/hello -I packages/compiler/src/runtime -lpthread -std=c11
./dist/hello
```

Флаги:
- `-I packages/compiler/src/runtime` — путь к `runtime.h` (внутри репозитория tsclang)
- `-lpthread` — threads (даже если не используются, runtime может ссылаться)
- `-std=c11` — C11 стандарт

## Способ 4: tsclang build --emit binary

```bash
tsclang build hello.tsc --out-dir dist --emit binary
./dist/hello
```

Компилирует в C, затем вызывает gcc автоматически.

## С оптимизацией

```bash
tsclang build hello.tsc --out-dir dist --emit binary --optimize O2 --command "./dist/hello"
```

Передаёт флаг `-O2` в gcc.

## Режим наблюдения (watch)

```bash
tsclang build hello.tsc --out-dir dist --watch
```

Пересобирается при изменении `hello.tsc`. Удобно при разработке.
