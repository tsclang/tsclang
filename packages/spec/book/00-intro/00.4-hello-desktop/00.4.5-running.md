# 00.4.5 Сборка и запуск

## Способ 1: build --emit exec (рекомендуется для разработки)

```bash
tsclang build hello.tsc --out-dir dist --emit exec
```

Компилирует, собирает бинарник gcc и сразу запускает его — прямым spawn, без shell:
одна команда одинаково работает на Linux, macOS и Windows (не нужно помнить про
`./dist/hello` против `dist\hello`). Бинарник остаётся в `dist/` — повторный запуск
без пересборки: `./dist/hello`. Код выхода программы становится кодом выхода CLI.

С аргументами (argv живёт в строке команды — выпускаемся в `--command`):

```bash
tsclang build hello.tsc --emit binary --command "./dist/hello arg1 arg2"
```

## Способ 2: ручная сборка через CMake

```bash
tsclang build hello.tsc --out-dir dist
cd dist
cmake .
make
./hello
```

Результат:
```
Hello, World!
```

## Способ 3: ручная компиляция через gcc

```bash
tsclang build hello.tsc --out-dir dist
gcc dist/hello.c -o dist/hello -I packages/compiler/src/runtime -lpthread -std=c11
./dist/hello
```

Флаги:
- `-I packages/compiler/src/runtime` — путь к `runtime.h` (внутри репозитория tsclang)
- `-lpthread` — threads (даже если не используются, runtime может ссылаться)
- `-std=c11` — C11 стандарт

## Способ 4: tsclang build --emit binary

```bash
tsclang build hello.tsc --out-dir dist --emit binary
./dist/hello
```

Компилирует в C, затем вызывает gcc автоматически.

## С оптимизацией

```bash
tsclang build hello.tsc --out-dir dist --emit exec --optimize O2
```

Передаёт флаг `-O2` в gcc.

## Режим наблюдения (watch)

```bash
tsclang build hello.tsc --out-dir dist --watch --emit exec
```

Пересобирается при изменении `hello.tsc` и перезапускает программу (перед перезапуском
прошлое дерево процессов завершается). Удобно при разработке.
