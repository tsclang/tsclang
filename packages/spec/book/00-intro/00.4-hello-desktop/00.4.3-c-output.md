# 00.4.3 Разбор C-output

Исходный код:

```typescript
console.log("Hello, World!");
```

Сгенерированный C:

```c
#include "runtime.h"

int main(void) {
    TSC_INIT();
    printf("Hello, World!\n");
    return 0;
}
```

Разбор построчно:

## `#include "runtime.h"`

Подключает TSClang runtime — header-only библиотеку. Содержит:
- Определение типов (`String`, `Result`, etc.)
- Макросы (`STR_LIT`, `TSC_INIT`)
- Inline-функции для работы со строками, массивами, Map/Set
- Math constants
- Platform-specific код (AVR, embedded, desktop)

Расположение: `src/runtime/runtime.h`. Компилируется с `-I src/runtime`.

## `int main(void) {`

Функция `main` — точка входа. TSClang оборачивает top-level код в `main`.

## `TSC_INIT();`

Инициализация runtime:
- На desktop: вызывает `clock_gettime(CLOCK_MONOTONIC)` для инициализации базового времени `performance.now()`
- На embedded: ring buffer для строк инициализируется через zero-init в BSS (`static size_t _tsc_str_pool_pos = 0;`), TSC_INIT — no-op
- На NES: no-op (нет `clock_gettime`)

## `printf("Hello, World!\n");`

`console.log("Hello, World!")` → `printf("Hello, World!\n")`.

Лексер видит, что аргумент — строковый литерал. Codegen генерирует `printf` с форматной строкой напрямую, без создания String struct.

## `return 0;`

Стандартный возврат из `main`. TSClang добавляет автоматически.

## Другие типы аргументов

```typescript
console.log(42);
```

```c
printf("%g\n", 42.0);
```

```typescript
console.log("count:", 3);
```

```c
printf("count: %g\n", 3.0);
```

Codegen мержит несколько аргументов в одну форматную строку `printf`. Это эффективнее, чем отдельные вызовы.
