# 00.4.2 Компиляция

```bash
tsclang build hello.tsc --out-dir dist
```

Что происходит:

1. CLI читает `hello.tsc`
2. Лексер разбивает текст на токены
3. Парсер строит AST
4. Codegen обходит AST и генерирует C-код
5. Записывает `dist/hello.c`
6. Генерирует `dist/CMakeLists.txt` (если не существует)

## Результат

```
dist/
  hello.c           — сгенерированный C-код
  CMakeLists.txt    — файл сборки CMake
```

## Опции компиляции

```bash
# Только C (по умолчанию)
tsclang build hello.tsc --out-dir dist

# Сразу в бинарник
tsclang build hello.tsc --out-dir dist --emit binary

# С оптимизацией
tsclang build hello.tsc --out-dir dist --optimize O2

# С отладочной информацией
tsclang build hello.tsc --out-dir dist --debug

# Режим наблюдения (пересборка при изменении)
tsclang build hello.tsc --out-dir dist --watch

# Показать все ошибки (без лимита)
tsclang build hello.tsc --out-dir dist --all-errors
```

## Важно: всегда указывайте --out-dir

При ручном запуске `tsclang build` ВСЕГДА указывайте `--out-dir` во временную папку:

```bash
tsclang build hello.tsc --out-dir .tsclang-tmp/
```

Без `--out-dir` артефакты (`.c`, `CMakeLists.txt`) попадут в текущую директорию и засорят её.
