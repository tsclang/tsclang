# 00.4.6 tsclang run

`tsclang run` — компиляция и запуск в одну команду.

```bash
tsclang run hello.tsc
```

## Что происходит

1. Читает `hello.tsc`
2. Компилирует в C
3. Создаёт временную директорию (`tmp/tsclang-XXXXXX/`)
4. Записывает C-файл
5. Вызывает `gcc` для компиляции в бинарник
6. Запускает бинарник
7. Удаляет временную директорию
8. Выходит с кодом возврата программы

## Передача аргументов

```bash
tsclang run hello.tsc -- arg1 arg2 arg3
```

Всё после `--` передаётся как аргументы запускаемой программе.

## Оптимизация

```bash
tsclang run hello.tsc --optimize O2
```

## Отличие от `tsclang build --emit binary`

| | `tsclang run` | `tsclang build --emit binary` |
|---|------|---------|
| Куда пишет | Временная директория | `--outDir` |
| Запускает | Да | Нет |
| Удаляет бинарник | Да | Нет |
| Для чего | Разработка | Продакшен |
