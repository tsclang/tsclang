# 00.4.1 Первый файл

Создайте файл `hello.tsc`:

```typescript
console.log("Hello, World!");
```

Это вся программа. Не нужен `function main()`, не нужны импорты, не нужны аннотации типов.

TSClang поддерживает **top-level code** — код на верхнем уровне файла выполняется как тело `main()`. Это отличается от C, где нужен `int main(void)`, и похоже на TypeScript/Python.

## Почему не нужен main?

TSClang автоматически оборачивает top-level код в C-функцию `main`:

```c
int main(void) {
    TSC_INIT();
    // ваш код здесь
    return 0;
}
```

`TSC_INIT()` — инициализация runtime (обнуление пулов, установка буферов). На desktop — практически no-op. На embedded — инициализация static buffers.

## Точка с запятой

В TSClang точка с запятой **опциональна**:

```typescript
console.log("Hello, World!")    // OK — без точки с запятой
console.log("Hello, World!");   // OK — с точкой с запятой
```

Это **не ASI** (Automatic Semicolon Insertion как в JavaScript). TSClang использует другой подход — парсер определяет конец выражения по контексту. Подробнее — в Block 1 (Лексика).
