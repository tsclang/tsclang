# 00.3.5 Кодогенерация (Codegen)

Codegen — финальная фаза. Обходит AST и генерирует C-код.

## Структура codegen

```
packages/compiler/src/compiler/codegen.ts   — точка входа, класс Context
packages/compiler/src/compiler/codegen/
  top-level.ts → top-level/      — объявления (ClassDecl, FuncDecl, Interface, Enum, TypeAlias)
  stmt.ts → stmt/                — операторы (VarDecl, If, For, While, match, destruct)
  expr.ts → expr/                — выражения (dispatch, operators, assign, literals)
  calls/                         — вызовы (call-dispatch, method-dispatch, console, stdlib, builtin)
  types.ts → types/              — типы (resolve, infer, helpers)
  misc.ts → misc/                — утилиты (emit-helpers, new-expr, closures, arrays)
  async.ts → async/              — async/await (async-stmt, async-emit, generator, helpers, scan)
  generics.ts                    — монорфизация дженериков
  borrow-tracker.ts              — ownership/borrow-статусы переменных
  scope-manager.ts               — стек скоупов (block scope, shadowing)
  output-buffer.ts               — накопление C-текста
```

## Класс Context

`Context` — центральный объект codegen. Содержит:

- **Таблица символов** — имя → тип + флаги
- **Стек вывода** — накопление C-кода
- **Счётчики** — уникальные имена для временных переменных
- **Флаги** — embedded, library mode, module prefix

## Пример: `let x = 42`

AST:
```json
{ "kind": "VarDecl", "name": "x", "init": { "kind": "Literal", "litType": "number", "value": "42" } }
```

Codegen обходит:
1. `VarDecl` → определяет тип (`number` → `f64` на desktop), объявляет в scope
2. `Literal` (`litType: "number"`) → генерирует `42.0`
3. Результат: `double x = 42.0;`

## Пример: `console.log("hello world")`

AST (упрощённо):
```json
{ "kind": "Call", "callee": { "kind": "Member", "object": "console", "prop": "log" }, "args": [ { "kind": "Literal", "litType": "string", "value": "hello world" } ] }
```

Codegen:
1. Распознаёт `console.log` — встроенный вызов
2. Аргумент — строковый литерал → `printf("hello world\n")`
3. Результат: `printf("hello world\n");`

## Type mapping

| TSClang | C |
|---------|---|
| `i8` | `int8_t` |
| `i16` | `int16_t` |
| `i32` | `int32_t` |
| `i64` | `int64_t` |
| `u8` | `uint8_t` |
| `u16` | `uint16_t` |
| `u32` | `uint32_t` |
| `u64` | `uint64_t` |
| `f32` | `float` |
| `f64` | `double` |
| `boolean` | `bool` |
| `usize` | `size_t` |
| `isize` | `ptrdiff_t` |
| `string` | `String` (struct) |
