# 00.5.5 Прошивка

После компиляции — `.hex` файл для прошивки:

## Сборка

```bash
# 1. Компиляция TSC → C
tsclang build src/main.tsc --outDir dist

# 2. Компиляция C → ELF
avr-gcc -Os -mmcu=atmega328p -I src/runtime -DTSC_EMBEDDED dist/main.c -o dist/main.elf

# 3. Конвертация ELF → HEX
avr-objcopy -O ihex dist/main.elf dist/main.hex
```

## Прошивка через avrdude

```bash
avrdude -c arduino -p atmega328p -P COM3 -b 115200 -U flash:w:dist/main.hex:i
```

Параметры:
- `-c arduino` — программатор (Arduino bootloader)
- `-p atmega328p` — микроконтроллер
- `-P COM3` — порт (Linux: `/dev/ttyUSB0`, macOS: `/dev/tty.usbmodem*`)
- `-b 115200` — скорость
- `-U flash:w:dist/main.hex:i` — записать flash

## Автоматизация через tsc.package.json

```json
{
  "builds": {
    "avr": {
      "target": "avr",
      "mcu": "atmega328p",
      "toolchain": "avr-gcc",
      "optimize": "Os"
    }
  }
}
```

```bash
tsclang build-cmake tsc.package.json --build avr
cmake --build . && avr-objcopy -O ihex main.elf main.hex
avrdude -c arduino -p atmega328p -P COM3 -b 115200 -U flash:w:main.hex:i
```
