# 00.5.2 C-output для AVR

Исходный код:

```typescript
console.log("Hello from AVR!");
```

TSClang генерирует **один и тот же** C-код для всех таргетов:

```c
#include "runtime.h"

int main(void) {
    TSC_INIT();
    printf("Hello from AVR!\n");
    return 0;
}
```

## Важно: TSClang не знает про AVR

TSClang-компилятор генерирует portable C. Он не делает разницы между desktop и AVR — `printf` генерируется всегда. Платформо-специфичная адаптация происходит на уровне C-компиляции:

1. **runtime.h** использует `#ifdef TSC_EMBEDDED` и `#ifdef __AVR__` для выбора реализаций
2. **avr-gcc** компилирует `printf` в минимальную реализацию для AVR
3. Строковые литералы попадают в PROGMEM через `STR_LIT` макрос, который раскрывается по-разному

Это разделение ответственности: TSClang → portable C, C-компилятор + runtime → платформо-специфичный код.

## Ключевые отличия runtime

### String struct

Desktop:
```c
typedef struct {
    const char *data;
    size_t      length;
    size_t      capacity;   /* 0 = rodata, >0 = heap */
    uint32_t   *_refcount;  /* NULL для rodata, heap counter для ARC */
} String;
```

Embedded:
```c
typedef struct {
    const char *data;
    size_t      length;
    size_t      capacity;   /* 0 = rodata/PROGMEM, >0 = ring buffer */
} String;
```

Нет `_refcount` — нет ARC. Нет heap — нет malloc/free.

### STR_LIT

Desktop:
```c
#define STR_LIT(s) ((String){ .data = (s), .length = sizeof(s) - 1, .capacity = 0, ._refcount = NULL })
```

AVR:
```c
#define STR_LIT(s) ((String){ .data = PSTR(s), .length = sizeof(s) - 1, .capacity = 0 })
```

`PSTR(s)` — макрос AVR-libc, помещающий строку в flash (PROGMEM) вместо RAM.

### retain/release

Desktop:
```c
static inline void tsc_string_retain(String s) {
    if (s._refcount) (*s._refcount)++;
}
static inline void tsc_string_release(String s) {
    if (s._refcount) {
        if (--(*s._refcount) == 0) { free(s._refcount); free((void*)s.data); }
    }
}
```

Embedded:
```c
static inline void tsc_string_retain(String s) { (void)s; }
static inline void tsc_string_release(String s) { (void)s; }
```

No-op — нет ARC, нет heap, строки живут вечно (rodata) или в ring buffer.
