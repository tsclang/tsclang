# 00.3.5 Кодогенерация (Codegen)

Codegen — финальная фаза. Обходит AST и генерирует C-код.

## Структура codegen

```
src/compiler/codegen.js          — точка входа, класс Context
src/compiler/codegen/
  top-level.js → top-level/      — объявления (ClassDecl, FuncDecl, Interface, Enum, TypeAlias)
  stmt.js → stmt/                — операторы (VarDecl, If, For, While, match, destruct)
  expr.js → expr/                — выражения (dispatch, operators, assign, literals)
  calls/                         — вызовы (call-dispatch, method-dispatch, console, stdlib, builtin)
  types.js → types/              — типы (resolve, infer, helpers)
  misc.js → misc/                — утилиты (emit-helpers, new-expr, closures, arrays)
  async.js → async/              — async/await (async-stmt, async-emit, generator, helpers, scan)
  generics.js                    — монорфизация дженериков
```

## Класс Context

`Context` — центральный объект codegen. Содержит:

- **Таблица символов** — имя → тип + флаги
- **Стек вывода** — накопление C-кода
- **Счётчики** — уникальные имена для временных переменных
- **Флаги** — embedded, library mode, module prefix

## Пример: `let x = 42`

AST:
```json
{ "kind": "VarDecl", "name": "x", "init": { "kind": "NumberLiteral", "value": 42 } }
```

Codegen обходит:
1. `VarDecl` → определяет тип (i32), объявляет в scope
2. `NumberLiteral` → генерирует `42`
3. Результат: `int32_t x = 42;`

## Пример: `console.log("hello world")`

AST:
```json
{ "kind": "CallExpr", "callee": "console.log", "args": ["hello world"] }
```

Codegen:
1. Распознаёт `console.log` — встроенный вызов
2. Аргумент — строковый литерал → `printf("hello world\n")`
3. Результат: `printf("hello world\n");`

## Type mapping

| TSClang | C |
|---------|---|
| `i8` | `int8_t` |
| `i16` | `int16_t` |
| `i32` | `int32_t` |
| `i64` | `int64_t` |
| `u8` | `uint8_t` |
| `u16` | `uint16_t` |
| `u32` | `uint32_t` |
| `u64` | `uint64_t` |
| `f32` | `float` |
| `f64` | `double` |
| `bool` | `bool` |
| `usize` | `size_t` |
| `string` | `String` (struct) |

## Реализация

Точка входа: `src/compiler/codegen.js`

Функция `codegen(ast, filename, src, opts)` → `{ c, warnings, exports }`.
