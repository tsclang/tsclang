# 00.3.4 Проверка типов (Typecheck)

Проверка типов в TSClang выполняется **inline** внутри codegen, а не отдельной фазой.

## Что проверяется

### Вывод типов

```typescript
let x = 42;        // x: i32 (выведено из литерала)
let s = "hello";   // s: string
let b = true;      // b: bool
```

### Совместимость типов

```typescript
let a: i32 = 42;
let b: f64 = a;    // OK: widening i32 → f64
let c: u8 = a;     // Error: narrowing требует явного cast
```

### Ownership

```typescript
let s = "hello";
let s2 = s;        // move — s больше нельзя использовать
console.log(s);    // Error: use after move
```

### throws

```typescript
function readFile(path: string): string throws IOError {
    // ...
}

let content = readFile("test.txt"); // Error: нужен try или ?
```

## Как работает

Контекст codegen (`Context`) содержит таблицу символов:

- Имя → тип + флаги (mut, moved, ref, ...)
- При обходе AST проверяет типы на совместимость
- При ошибке — добавляет в список ошибок

## Будущее

В планах — выделить typecheck в отдельную фазу перед codegen. Это позволит:
- Выдавать более точные ошибки
- Делать оптимизации на уровне типов
- Поддерживать incremental compilation

## Реализация

Inline в `src/compiler/codegen.ts` + `src/compiler/codegen/types/` (resolve, infer, helpers).
