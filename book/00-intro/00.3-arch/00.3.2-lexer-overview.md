# 00.3.2 Лексер

Лексер — первая фаза компиляции. Преобразует текст программы в последовательность токенов.

## Исходный код

```typescript
let x: i32 = 42;
```

## Результат лексера

| Токен | Тип |
|-------|-----|
| `let` | keyword |
| `x` | identifier |
| `:` | punctuation |
| `i32` | keyword (type) |
| `=` | operator |
| `42` | number |
| `;` | punctuation |

## Типы токенов

- **identifier** — имена переменных, функций, типов (`x`, `myFunc`, `String`)
- **keyword** — зарезервированные слова (`let`, `const`, `function`, `if`, `return`)
- **number** — числовые литералы (`42`, `3.14`, `0xFF`, `0b1010`)
- **string** — строковые литералы (`"hello"`, `` `template` ``)
- **char** — символьные литералы (`'a'`)
- **operator** — операторы (`+`, `-`, `*`, `==`, `&&`, `...`)
- **punctuation** — разделители (`(`, `)`, `{`, `}`, `;`, `,`, `:`)

## Как работает

Лексер читает текст символ за символом:

1. Пропускает пробелы и комментарии
2. Определяет тип токена по первому символу
3. Читает токен до конца
4. Записывает позицию (файл, строка, столбец) — для сообщений об ошибках

## Ошибки лексера

- Незакрытая строка: `"hello` — ошибка
- Незаконный символ: `@` вне декоратора — ошибка
- Некорректное число: `0xZZ` — ошибка

## Реализация

Файл: `src/compiler/lexer.ts`

Экспортирует функцию `lex(src, filename)` → массив токенов.
