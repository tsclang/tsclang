# 00.3.6 Таргеты

TSClang поддерживает несколько целевых платформ. Codegen адаптирует C-код под таргет.

## Desktop

Таргет по умолчанию. Полный heap, threads, libuv.

```c
#include "runtime.h"

int main(void) {
    TSC_INIT();
    // ...
    return 0;
}
```

`runtime.h` подключает:
- `<stdio.h>`, `<stdint.h>`, `<stdbool.h>`, `<stdlib.h>`, `<string.h>`
- `<stdatomic.h>` — для Atomic<T>
- `<math.h>` — для Math methods
- String struct (ARC, heap-allocated)

Сборка:
```bash
tsclang build hello.tsc --outDir dist
cd dist && cmake . && make
```

## Embedded (AVR)

Нет heap, нет OS, нет threads.

```c
#include "runtime.h"  // TSC_EMBEDDED defined

int main(void) {
    TSC_INIT();
    // ...
    return 0;
}
```

При `TSC_EMBEDDED`:
- String — rodata/PROGMEM, нет malloc
- Нет `<stdatomic.h>` — Atomic<T> использует plain bool/int
- Нет `<math.h>` — Math ограничен
- Массивы — статические, стек, BSS

Сборка:
```bash
tsclang build hello.tsc --outDir dist  # генерирует C
avr-gcc -Os -mmcu=atmega328p -I src/runtime dist/hello.c -o dist/hello.elf
```

## WASM

Через Emscripten.

```bash
tsclang build hello.tsc --emit wasm --outDir dist
```

Использует `runtime_wasm.h` вместо `runtime.h`.

## Runtime-файлы по платформам

```
src/runtime/
  runtime.h          — desktop (основной)
  runtime_wasm.h     — WASM
  runtime_avr/       — AVR-специфичные helpers
  runtime_nes.h      — NES
  runtime_genesis.h  — Sega Genesis
  runtime_spectrum.h — ZX Spectrum
  runtime_dos.h      — MS-DOS
  runtime_ps1.h      — PlayStation 1
  runtime_ps2.h      — PlayStation 2
  platforms/         — platform profiles
  std/               — stdlib реализации
```

## Как таргет влияет на codegen

| Фича | Desktop | Embedded (AVR) | WASM |
|------|---------|----------------|------|
| String | ARC, heap | rodata, PROGMEM | ARC |
| Массивы | heap (malloc/realloc) | стек/BSS | heap |
| Threads | да (pthreads) | нет | нет |
| Atomic | `<stdatomic.h>` | plain int/bool | `<stdatomic.h>` |
| Async | libuv event loop | cooperative scheduler | custom loop |
| Math | полный | ограниченный | полный |
| console.log | printf | USART_Transmit | printf |
| Map/Set | heap hash table | static hash table | heap hash table |

## Выбор таргета

Таргет определяется через `tsc.package.json`:

```json
{
  "builds": {
    "avr": {
      "target": "avr",
      "mcu": "atmega328p"
    }
  }
}
```

Или через CLI (в будущем):
```bash
tsclang build hello.tsc --target avr
```
