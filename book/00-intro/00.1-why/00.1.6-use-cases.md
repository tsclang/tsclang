# 00.1.6 Области применения

TSClang покрывает спектр от серверного кода до bare metal.

## Сейчас

### Серверный код
HTTP-серверы, WebSocket, REST API, бэкенд-сервисы. TSClang компилируется в нативный код — скорость C, синтаксис TypeScript.

```typescript
import { serve } from "std/net";

serve({ port: 8080 }, (req) => {
    return new Response("Hello from TSClang!");
});
```

### Десктопные приложения
CLI-утилиты, TUI-приложения, файловые менеджеры, инструменты разработки. Нативный код без GC pauses.

```typescript
import { readFile } from "std/fs";

const content = readFile("config.json");
console.log(content);
```

## Важно

### Системный уровень
Драйверы, утилиты ОС, системные инструменты. C-бэкенд позволяет работать на уровне, недоступном для TS.

### Embedded
Arduino, ESP32, STM32, AVR. Код на TSClang компилируется через avr-gcc и работает на микроконтроллерах.

```typescript
@embedded.noHeap
function main(): void {
    const led: u8 = 13;
    // blink LED
}
```

### Игры
Через OpenGL, DirectX, SDL. Нативная производительность + удобный синтаксис.

## Мечта

### Кросс-платформа
Windows, Linux, macOS, Android, iOS — один код, разные платформы.

### Ретро-платформы
ZX Spectrum, NES, Sega Genesis, MS-DOS, PlayStation 1/2. TSClang уже имеет runtime-заголовки для этих платформ:

```
src/runtime/runtime_nes.h
src/runtime/runtime_spectrum.h
src/runtime/runtime_genesis.h
src/runtime/runtime_dos.h
src/runtime/runtime_ps1.h
src/runtime/runtime_ps2.h
```

### Собственный ретро-ПК
Операционная система и игры, написанные на TSClang, для собственного железа.

## Приоритеты по платформам

| Приоритет | Платформа | Статус |
