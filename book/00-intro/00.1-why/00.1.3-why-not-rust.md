# 00.1.3 Почему не Rust

Rust — замечательный язык. Он решает проблемы безопасности памяти, которые TSClang тоже решает. Но у Rust есть своя цена.

## Кривая обучения

Rust — один из самых сложных для изучения языков. Причины:

### Lifetimes

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

Аннотации lifetime — уникальная концепция Rust. Нет ни одного другого языка, где программист указывал бы lifetime явно. Это мощный инструмент, но он требует понимания, которое не переносится из других языков.

### Borrow checker

```rust
let mut v = vec![1, 2, 3];
let first = &v[0];
v.push(4); // error: cannot borrow `v` as mutable because it is also borrowed as immutable
```

Borrow checker Rust — строгий. Он запрещает паттерны, которые программист считает безопасными, но не может доказать это компилятору. Борьба с borrow checker — основной источник фрустрации при изучении Rust.

### Ownership семантика

```rust
let s1 = String::from("hello");
let s2 = s1; // s1 moved, нельзя использовать
println!("{}", s1); // error: value borrowed here after move
```

Концепция move — не проблема сама по себе. Проблема — в том, что она взаимодействует с borrow checker, lifetimes, traits и другими механизмами, создавая сложные зависимости.

## Синтаксис

Rust не похож ни на один мейнстрим-язык:

```rust
fn main() {
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    for i in &v {
        println!("{}", i);
    }
}
```

`fn`, `let mut`, `Vec::new()`, `&v`, `for i in` — программисту на TypeScript/Python/Java нужно учить всё с нуля.

## Экосистема

Cargo — лучший пакетный менеджер в системном программировании. Но:
- Rust компилируется медленно (особенно с процедурными макросами)
- Бинарники большие (много monomorphization, debug info)
- FFI с C — возможен, но не идиоматичен (Rust хочет быть хозяином мира)

## Что делает TSClang иначе

- **Нет lifetime-аннотаций** — borrow checker использует scope-based lifetime, без аннотаций программиста
- **TS-синтаксис** — `function`, `let`, `const`, `class`, `interface`, `console.log()` — знакомо любому TS-разработчику
- **Проще borrow checker** — меньше правил, больше паттернов разрешено, но безопасность сохраняется
- **Компиляция в C** — не LLVM, не свой бэкенд. Любой C-компилятор работает — gcc, clang, avr-gcc, emcc

### Компромисс

TSClang не заменяет Rust. Rust — более мощный и выразительный язык. TSClang — более простой и доступный. Компромисс:

| | Rust | TSClang |
|---|------|---------|
| Memory safety | Полная (lifetimes + borrow checker) | Частичная (scope-based lifetime) |
| Синтаксис | Уникальный | TypeScript-подобный |
| Кривая обучения | Высокая | Низкая (для TS-разработчиков) |
| Таргеты | Desktop, server, WASM | Desktop, server, embedded, retro, WASM |
| Компиляция | LLVM (медленная) | C (быстрая) |
| Interop | C FFI (unsafe) | Inline C, .d.tsc, native {} |
