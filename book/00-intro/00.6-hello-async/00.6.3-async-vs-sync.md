# 00.6.3 Sync vs Async main

## Синхронный main

```typescript
console.log("Hello!");
```

```c
int main(void) {
    TSC_INIT();
    printf("Hello!\n");
    return 0;
}
```

Прямолинейно. Код выполняется последовательно. Нет state machine, нет poll loop.

## Асинхронный main

```typescript
async function main(): Promise<void> {
    console.log("Hello!");
}
```

```c
typedef struct { int32_t _state; bool _done; } main_state;
static void main_poll(main_state *self) { ... }
int main(void) {
    TSC_INIT();
    main_state _main_sm = {0};
    while (!_main_sm._done) { main_poll(&_main_sm); }
    return 0;
}
```

Больше кода, но позволяет `await`.

## Когда использовать sync, когда async

### Sync — когда нет I/O

```typescript
let result = fibonacci(30);
console.log(result);
```

Нет network, нет file I/O, нет timers — sync достаточно.

### Async — когда есть I/O

```typescript
async function main(): Promise<void> {
    const data = await fetch("https://api.example.com/data");
    console.log(data);
}
```

Network, file I/O, timers, concurrency — нужен async.

### На embedded

```typescript
#[target(avr)]
async function main(): void {
    console.log("boot");
    while (true) {
        await delay(500);
        toggle_led();
    }
}
```

Embedded почти всегда async — cooperative scheduler для обработки событий, timers, interrupts.

## Top-level await

В TSClang нет top-level `await` (пока). Для использования `await` нужна `async function main()`:

```typescript
// ОШИБКА: top-level await не поддерживается
// const data = await fetch("...");

// ПРАВИЛЬНО:
async function main(): Promise<void> {
    const data = await fetch("...");
}
```
